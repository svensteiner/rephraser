    Was die Anwendung nicht macht: Sie sendet Eingabe, Ergebnis und geöffnete Dateien nicht an diese Website, GitHub oder eine Cloud-API. GitHub Pages liefert nur die Programmdateien aus. Browser, Betriebssystem und Erweiterungen können eigene Einstellungen für Zwischenablage, Downloads oder Formularwiederherstellung haben.

    Was diese Ausgabe kann: Feste, nachvollziehbare Bereinigung und kleine Formulierungsglättungen. Sie verwendet kein Mistral-Modell und keine Cloud-API.

    Wichtig: Die Browser-Ausgabe ist kein Beweis für gleiche Bedeutung. Bitte wichtige Texte vor dem Versenden selbst lesen.
